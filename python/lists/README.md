### Python Lists

|# | Challenge | Description |
| :---     | :----:   | ---:     |
|1.| Second Largest | Given a list of integers nums, write a function that returns the second largest distinct number. Return None if fewer than two distinct numbers exist.  | 
|2.| Move Zeros | Given a list of integers nums, move all 0s to the end while keeping the relative order of all non-zero elements. Do it in-place with $O(1)$ extra space.|
